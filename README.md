# BSS-Course-Projects

This repository contains various implementations and experiments related to **Blind Source Separation (BSS)** and other signal processing techniques. These projects aim to solve different signal processing and estimation problems using advanced mathematical and computational methods.

### Topics :

1. **Solving BSS Problem Using Geometric Interpretation**  
   - This project tackles the Blind Source Separation (BSS) problem using geometric interpretation methods for source extraction and separation.

2. **Implementing Optimization Methods**  
   - **Steepest Descent**
   - **Newton's Method**
   - **Alternating Minimization**
   - **Gradient Projection**  
   These optimization algorithms are implemented to solve various mathematical and signal processing challenges.

3. **Principal Component Analysis (PCA)**  
   - Implementing PCA for dimensionality reduction and feature extraction in high-dimensional datasets.

4. **Singular Value Decomposition (SVD) & Angle Estimation Using Beamforming and MUSIC**  
   - This project applies Singular Value Decomposition (SVD) and uses beamforming and the MUSIC (Multiple Signal Classification) method for angle estimation in signal processing.

5. **Common Spatial Pattern (CSP) and Canonical Correlation Analysis (CCA)**  
   - Implementing **CSP** and **CCA** techniques to solve Brain-Computer Interface (BCI) problems by analyzing EEG data for optimal feature extraction.

6. **Uncorrelated and Non-Stationary Sources with Mutually Correlated Components** 
   - Implemented **Joint Diagonalization algorithms** to separate and analyze correlated non-stationary sources.

7. **Sparse Recovery Problems** 
   - Implemented several sparse recovery algorithms including:  
      - Subset Selection**  
      - Matching Pursuit (MP) 
      - Orthogonal Matching Pursuit (OMP)
      - Basis Pursuit (BP)
      - Iteratively Reweighted Least Squares (IRLS) 
   - Evaluated performance under both known and unknown sparsity levels.

8. **LASSO and Dictionary Learning**  
   - Solved **LASSO** problems under noisy conditions.  
   - Investigated the effects of **mutual coherence** on recovery accuracy.  
   - Implemented **K-SVD** and **MOD** algorithms for dictionary learning.  
   - Applied **single-channel sparse blind deconvolution** for signal reconstruction.

9. **Blind Source Separation for Independent Sources** 
   - Minimized **Kullback–Leibler divergence (D<sub>KL</sub>)** using **Mean Squared Error (MSE)** estimation of the score function.  
   - Implemented **deflation** and **equivariant** methods for source extraction.

10. **Blind Source Separation (BSS) for Non-Gaussian Sources**
   - Maximized **kurtosis** using **FastICA** with both **deflationary** and **symmetric** approaches.

---

### **Final Project: Motor Imagery Classification**
   - Classified **four movement types**: right arm, right thumb, right foot, and no movement.  
   - Applied **Common Spatial Patterns (CSP)** for feature extraction.  
   - Performed **training**, **validation**, and **testing** using LDA classifiers.
